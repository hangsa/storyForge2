> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Inspiration Router (v1.7 F1.7.7 — completing AC-8, formalized in v1.9 §五 F1.9.6 + F1.9.7). Capture, classify, store, and surface ideas from agent conversations and user interactions across all 6 stages, with a manual capture button, user correction operations, sensitivity control, and a cross-project Idea Pool import toggle for the new-project wizard.

**Architecture:** New `backend/inspiration/` package provides (a) `idea_pool.py` thin facade over the existing `backend/creative_os/idea_pool.py` storage, (b) `classifier.py` Tier 3 LLM call that returns a 5-category confidence distribution (~50 in / ~30 out tokens), (c) `router.py` orchestrator with `catch_from_conversation(turns)`, `capture(text, stage, context)`, and the 5 user-correction operations (reclassify, split, merge, mark_invalid, edit). Multi-class gap rules (≥0.8 single, 0.5–0.8 needs_review, >0.3 gap → top label, ≤0.3 gap → dual "cross-class" label) are pure-function logic. REST API at `backend/api/inspiration.py` (7 endpoints) plus 2 endpoints for cross-project browse. Sensitivity config (`low` ≥0.85 / `medium` ≥0.5 / `high` ≥0.0) lives at `backend/api/settings_api.py` per-project in `project.json` under `inspiration_sensitivity`. Frontend: new `InspirationPanel.tsx` (list/filter/edit/merge/split/capture), `SettingsPage.tsx` gains an "灵感路由器" tab with sensitivity dropdown + link to panel, Stage discussion components gain "捕捉灵感" button, and the new-project wizard gains a Step 1 "从已有项目借鉴灵感" toggle.

**Tech Stack:** Python 3.11 (FastAPI + Pydantic v1), React 18 + TypeScript + Vite + Tailwind, pytest + vitest + @testing-library/react. Tier 3 (Claude Haiku) per `config/model_tiers.yaml`.

**Spec ambiguities resolved during planning:**
1. **IdeaPool location** — v1.7 TRD L230 places `inspiration/router.py` *and* `inspiration/classifier.py` as siblings in `backend/inspiration/`, while F1.7.1.1 already has a working `IdeaPool` at `backend/creative_os/idea_pool.py`. The plan keeps `IdeaPool` where it is (CreativeOS is the rightful home for the Idea Pool concept) and puts the router + classifier in `backend/inspiration/`. The router *imports* `IdeaPool` from `backend.creative_os` — no duplication.
2. **Source stage values for manual capture** — v1.7 spec lists `STAGE_1..STAGE_5`, `INIT`, `MANUAL`, `INSPIRATION_ROUTER`. The plan treats `MANUAL` as the source_stage for user-clicked capture and `INSPIRATION_ROUTER` for all automatic captures; cross-project import uses `source_stage="IMPORTED"` to distinguish provenance.
3. **Cross-project access** — F1.9.7 says "v1.9 only does in-project Idea Pool filtering via the new-project wizard". The plan implements this as: the wizard step lists *other* projects' ideas via a new `GET /api/v1/projects/{id}/ideas?cross_project=true` filter (read-only), then `POST /api/v1/projects/{new_id}/ideas/bulk-import` writes the chosen ones into the new project's Idea Pool with `source_stage="IMPORTED"`. Global cross-project Idea Pool remains v1.10.
4. **Sensitivity threshold per stage** — design doc only says "low ≥0.85, high all-capture". The plan adds a small refinement: when the capture text is a *user manual capture*, sensitivity is ignored (manual intent is explicit). Sensitivity applies only to automatic `catch_from_conversation`.

```python
# backend/inspiration/models.py
"""Inspiration Router data models — pure dataclasses, zero LLM."""
from __future__ import annotations

from dataclasses import dataclass, field


# The five canonical Idea categories per F1.7.1.1 + F1.9.6 L413-418.
IDEA_CATEGORIES: tuple[str, ...] = (
    "设定灵感",
    "剧情想法",
    "角色灵感",
    "风格偏好",
    "写作灵感",
)


@dataclass
class ConversationTurn:
    """One message in an agent or user conversation."""
    role: str            # "user" | "assistant" | "system"
    content: str
    turn_index: int = 0  # monotonically increasing within a conversation


@dataclass
class ClassificationResult:
    """Raw Tier 3 classifier output for one piece of text."""
    text: str
    scores: dict[str, float]   # category -> confidence in [0, 1]

    def top_category(self) -> str:
        return max(self.scores, key=self.scores.get)

    def top_confidence(self) -> float:
        return self.scores[self.top_category()]

    def sorted_alternates(self) -> list[tuple[str, float]]:
        """Return categories other than top, sorted by score desc."""
        top = self.top_category()
        return sorted(
            ((c, s) for c, s in self.scores.items() if c != top),
            key=lambda x: x[1],
            reverse=True,
        )

    def gap_to_second(self) -> float:
        """Confidence gap between top and second-highest category."""
        alts = self.sorted_alternates()
        if not alts:
            return self.top_confidence()
        return self.top_confidence() - alts[0][1]


@dataclass
class StoredIdea:
    """The idea object the router writes to IdeaPool after applying
    multi-class rules (see F1.9.6 L404-407).

    `labels` is the multi-tag list (size 1 when single-class,
    size 2 when cross-class dual label). `tags` is supplementary
    markers like 'needs_review', 'cross_class', 'manual_capture'.
    """
    id: str
    content: str
    category: str                          # primary category (top of labels)
    labels: list[str] = field(default_factory=list)
    confidence: float = 0.0
    source_stage: str = "INSPIRATION_ROUTER"
    source_context: str = ""
    tags: list[str] = field(default_factory=list)

    def to_idea_kwargs(self) -> dict:
        """Project to Idea dataclass kwargs (IdeaPool uses kwargs add)."""
        return {
            "id": self.id,
            "content": self.content,
            "category": self.category,
            "source_stage": self.source_stage,
            "source_context": self.source_context,
            "related_elements": [],
            "confidence": self.confidence,
            "status": "active",
        }
```

```python
# backend/inspiration/classifier.py
"""InspirationClassifier — Tier 3 LLM call to score a piece of text
across the 5 Idea Pool categories.

Per F1.9.6 L396-407 the classifier is a single short call (~50 in / ~30
out tokens) returning a JSON distribution. Multi-class gap logic is NOT
this module's job — see router.apply_multi_class_rules().
"""
from __future__ import annotations

import json
import logging
import re
from pathlib import Path

from backend.inspiration.models import (
    ClassificationResult, IDEA_CATEGORIES,
)
from backend.llm.model_router import ModelRouter
from backend.utils.json_parser import parse_json_text

logger = logging.getLogger(__name__)


PROMPTS_PATH = (
    Path(__file__).parent / "prompts" / "inspiration_classify.yaml"
)


class InspirationClassifier:
    def __init__(self, model_router: ModelRouter, prompts_dir: Path | None = None):
        self._router = model_router
        # Resolve prompts dir: caller can override (tests); default is
        # the YAML shipped alongside this module.
        self._prompts_dir = Path(prompts_dir) if prompts_dir else PROMPTS_PATH.parent
        self._system_prompt, self._user_template = self._load_prompts()

    def _load_prompts(self) -> tuple[str, str]:
        """Read inspiration_classify.yaml from disk once at construction.

        The YAML shape:
          inspiration_classify:
            system_prompt: |
              ...
            user_prompt_template: |
              ...
        """
        import yaml

        path = self._prompts_dir / "inspiration_classify.yaml"
        if not path.exists():
            # Hardcoded fallback so the classifier still works if YAML is missing.
            system = (
                "你是一位创意分类助手。对输入文本在 5 个类别上打分"
                "（设定灵感/剧情想法/角色灵感/风格偏好/写作灵感），"
                "返回 JSON 对象 {category: float}，score ∈ [0, 1]，"
                "所有类别之和约为 1。"
            )
            user_tpl = "文本：{text}\n当前阶段：{stage}\n请输出 JSON 分类分布："
            return system, user_tpl

        with open(path, "r", encoding="utf-8") as f:
            data = yaml.safe_load(f) or {}
        block = data.get("inspiration_classify", {})
        return (
            block.get("system_prompt", ""),
            block.get("user_prompt_template", "{text}\n{stage}"),
        )

    async def classify(self, text: str, stage: str = "UNKNOWN") -> ClassificationResult:
        """Score `text` across all 5 categories using Tier 3 model."""
        if not text or not text.strip():
            return ClassificationResult(text=text or "", scores={c: 0.0 for c in IDEA_CATEGORIES})

        messages = [
            {"role": "system", "content": self._system_prompt},
            {"role": "user", "content": self._user_template.format(text=text, stage=stage)},
        ]

        try:
            result = await self._router.execute(
                agent_name="inspiration_router",
                task_name="classify",
                messages=messages,
                json_mode=True,
                temperature=0.0,        # deterministic for reproducibility
                max_tokens=128,          # ~30 tokens is enough for 5 floats
            )
        except Exception as e:
            logger.warning("InspirationClassifier router.execute failed: %s", e)
            return ClassificationResult(text=text, scores={c: 0.0 for c in IDEA_CATEGORIES})

        raw = result.get("content", "") or ""
        scores = self._parse_scores(raw)
        return ClassificationResult(text=text, scores=scores)

    @staticmethod
    def _parse_scores(raw: str) -> dict[str, float]:
        """Extract {category: float} from the LLM response.

        Handles:
        - Pure JSON
        - ```json ... ``` wrapped
        - Missing categories → default to 0.0
        - Out-of-range scores → clamp to [0, 1]
        """
        # Strip codefence if present
        raw = raw.strip()
        m = re.match(r"^```(?:json)?\s*(.*?)\s*```$", raw, re.DOTALL)
        if m:
            raw = m.group(1)

        try:
            obj = parse_json_text(raw)
        except Exception:
            try:
                obj = json.loads(raw)
            except Exception:
                logger.warning("Could not parse classifier JSON: %r", raw[:200])
                return {c: 0.0 for c in IDEA_CATEGORIES}

        if not isinstance(obj, dict):
            return {c: 0.0 for c in IDEA_CATEGORIES}

        scores: dict[str, float] = {}
        for cat in IDEA_CATEGORIES:
            v = obj.get(cat, 0.0)
            try:
                v = float(v)
            except (TypeError, ValueError):
                v = 0.0
            v = max(0.0, min(1.0, v))
            scores[cat] = v
        return scores
```

```python
conversations and user input.

F1.9.6 L376-449 — captures, classifies, stores, and surfaces ideas across
all 6 stages with user-correction operations.

# Sensitivity threshold (F1.9.6 L440)
SENSITIVITY_THRESHOLDS: dict[str, float] = {
    "low": 0.85,      # only very confident captures
    "medium": 0.5,    # 0.5+ confidence (matches the medium-conf branch)
    "high": 0.0,      # capture everything
}


def _normalize_text(text: str) -> str:
    """Whitespace + case fold for idempotency dedup."""
    return re.sub(r"\s+", "", text).strip().lower()


def _content_hash(text: str) -> str:
    """Short hash for dedup. SHA1 truncated to 12 chars."""
    return hashlib.sha1(_normalize_text(text).encode("utf-8")).hexdigest()[:12]


def apply_multi_class_rules(result: ClassificationResult) -> StoredIdea:
    """Apply the F1.9.6 L404-407 four-branch multi-class logic.

    Branches (priority order):
    1. All-zero scores → first category (设定灵感) + needs_review
    2. Top confidence ≥ 0.8:
       - Gap > 0.3 → single label, no tags
       - Gap ≤ 0.3 → dual label + cross_class
    3. Top confidence 0.5–0.8:
       - Gap > 0.3 → single label + needs_review
       - Gap ≤ 0.3 → dual label + needs_review + cross_class
    4. Top confidence < 0.5:
       - Gap > 0.3 → single label + needs_review
       - Gap ≤ 0.3 → dual label + needs_review + cross_class
    """
    scores = result.scores or {c: 0.0 for c in IDEA_CATEGORIES}

    # Branch 1: all-zero fallback
    if all(v == 0.0 for v in scores.values()):
        return StoredIdea(
            id=f"idea_{_content_hash(result.text)}",
            content=result.text,
            category=IDEA_CATEGORIES[0],
            labels=[IDEA_CATEGORIES[0]],
            confidence=0.0,
            tags=["needs_review"],
        )

    top = max(scores, key=scores.get)
    top_conf = scores[top]
    alts = sorted(
        ((c, s) for c, s in scores.items() if c != top),
        key=lambda x: x[1],
        reverse=True,
    )
    gap = top_conf - (alts[0][1] if alts else 0.0)

    tags: list[str] = []
    if top_conf < 0.8:
        tags.append("needs_review")

    if gap <= 0.3 and alts and alts[0][1] > 0.0:
        # Branch: small gap → dual label cross-class
        labels = [top, alts[0][0]]
        tags.append("cross_class")
    else:
        labels = [top]

    return StoredIdea(
        id=f"idea_{_content_hash(result.text)}",
        content=result.text,
        category=top,
        labels=labels,
        confidence=top_conf,
        tags=tags,
    )
```

```python
    top_conf = scores[top]
    alts = sorted(
        ((c, s) for c, s in scores.items() if c != top),
        key=lambda x: x[1],
        reverse=True,
    )
    gap = top_conf - (alts[0][1] if alts else 0.0)

    tags: list[str] = []
    if top_conf < 0.8:
        tags.append("needs_review")
    if gap <= 0.3 and alts and alts[0][1] > 0.0:
        labels = [top, alts[0][0]]
        tags.append("cross_class")
    else:
        labels = [top]

    return StoredIdea(
        id=f"idea_{_content_hash(result.text)}",
        content=result.text,
        category=top,
        labels=labels,
        confidence=top_conf,
        tags=tags,
    )


class InspirationRouter:
    """Orchestrates idea capture, classification, storage, and user corrections.

    Usage:
        router = InspirationRouter(classifier=clf, idea_pool=pool, project_id="p")
        stored = await router.catch_from_conversation(turns, stage="STAGE_1")
        await router.capture("Some thought", stage="STAGE_3")

    Sensitivity (per F1.9.6 L440):
        - "low": only ≥0.85 confidence captures are stored (auto path only)
        - "medium": ≥0.5
        - "high": all (≥0.0)
    Manual `capture()` calls bypass sensitivity — user intent is explicit.
    """

    def __init__(
        self,
        classifier: InspirationClassifier,
        idea_pool: IdeaPool,
        project_id: str,
    ):
        self.classifier = classifier
        self.idea_pool = idea_pool
        self.project_id = project_id

    # --- Conversation capture ---

    async def catch_from_conversation(
        self,
        turns: list[ConversationTurn],
        stage: str = "UNKNOWN",
        sensitivity: str = "medium",
        include_roles: tuple[str, ...] = ("user",),
    ) -> list[StoredIdea]:
        """Classify each eligible turn and persist as Idea.

        Idempotent: re-running with the same turns does not create duplicates
        (IdeaPool.add overwrites by id, and id is derived from content hash).
        Returns the list of newly-persisted StoredIdea objects.
        """
        threshold = SENSITIVITY_THRESHOLDS.get(sensitivity, 0.5)
        stored: list[StoredIdea] = []
        for turn in turns:
            if turn.role not in include_roles:
                continue
            text = (turn.content or "").strip()
            if not text or len(text) < 4:
                continue
            result = await self.classifier.classify(text, stage=stage)
            idea = apply_multi_class_rules(result)
            if idea.confidence < threshold:
                continue
            idea.source_stage = "INSPIRATION_ROUTER"
            idea.source_context = (
                f"{stage} conversation turn {turn.turn_index}"
            )
            self._persist(idea)
            stored.append(idea)
        return stored

    async def capture(
        self,
        text: str,
        stage: str = "UNKNOWN",
        context: str = "",
        sensitivity: str = "medium",
    ) -> Optional[StoredIdea]:
        """Manual capture (user clicked '捕捉灵感').

        Sensitivity is intentionally ignored — the user explicitly asked.
        """
        text = (text or "").strip()
        if not text:
            return None
        result = await self.classifier.classify(text, stage=stage)
        idea = apply_multi_class_rules(result)
        idea.source_stage = "MANUAL"
        idea.source_context = context or "user manual capture"
        idea.tags = list(idea.tags) + ["manual_capture"]
        self._persist(idea)
        return idea

    # --- User corrections (F1.9.6 L426-435) ---

    def reclassify(self, idea_id: str, new_category: str) -> None:
        """Move an idea to a different category."""
        if new_category not in IDEA_CATEGORIES:
            raise ValueError(f"Unknown category: {new_category}")
        self.idea_pool.update(idea_id, category=new_category)

    def edit(self, idea_id: str, new_content: str) -> None:
        """Refine an idea's text. Re-hashes the id so dedup reflects new content."""
        old = self.idea_pool.get(idea_id)
        if old is None:
            return
        new_content = (new_content or "").strip()
        if not new_content:
            return
        new_id = f"idea_{_content_hash(new_content)}"
        # If the new id collides with an existing idea, drop the old one and
        # keep the existing one (no merge — that's a separate operation).
        if self.idea_pool.get(new_id) is not None and new_id != idea_id:
            self.idea_pool.delete(idea_id)
            return
        # Update content; if id changed, rebuild the entry under the new id.
        self.idea_pool.delete(idea_id)
        from backend.models.creative_os import IdeaCategory, Idea
        old.status = old.status or "active"
        replacement = Idea(
            id=new_id,
            content=new_content,
            category=IdeaCategory(old.category.value if hasattr(old.category, "value") else old.category),
            source_stage=old.source_stage,
            source_context=old.source_context,
            related_elements=old.related_elements,
            confidence=old.confidence,
            status=old.status,
        )
        self.idea_pool.add(replacement)

    def mark_invalid(self, idea_id: str) -> None:
        self.idea_pool.update(idea_id, status="invalid")

    def split(self, idea_id: str, new_contents: list[str]) -> list[str]:
        """Replace one idea with N new ideas (different contents)."""
        old = self.idea_pool.get(idea_id)
        if old is None:
            return []
        new_ids: list[str] = []
        from backend.models.creative_os import IdeaCategory, Idea
        for text in new_contents:
            text = (text or "").strip()
            if not text:
                continue
            new_id = f"idea_{_content_hash(text)}"
            if self.idea_pool.get(new_id) is not None:
                continue  # skip duplicates
            replacement = Idea(
                id=new_id,
                content=text,
                category=IdeaCategory(old.category.value if hasattr(old.category, "value") else old.category),
                source_stage=old.source_stage,
                source_context=f"split from {idea_id}",
                related_elements=old.related_elements,
                confidence=old.confidence,
                status=old.status,
            )
            self.idea_pool.add(replacement)
            new_ids.append(new_id)
        self.idea_pool.delete(idea_id)
        return new_ids

    def merge(self, idea_ids: list[str]) -> Optional[str]:
        """Combine N ideas into one. Keeps the longest content as canonical."""
        ideas = [self.idea_pool.get(i) for i in idea_ids]
        ideas = [i for i in ideas if i is not None]
        if not ideas:
            return None
        canonical = max(ideas, key=lambda i: len(i.content))
        canonical_content = canonical.content
        merged_id = f"idea_{_content_hash(canonical_content)}"
        from backend.models.creative_os import IdeaCategory, Idea
        replacement = Idea(
            id=merged_id,
            content=canonical_content,
            category=IdeaCategory(canonical.category.value if hasattr(canonical.category, "value") else canonical.category),
            source_stage=canonical.source_stage,
            source_context=f"merged from {', '.join(idea_ids)}",
            related_elements=canonical.related_elements,
            confidence=max(i.confidence for i in ideas),
            status=canonical.status,
        )
        # Drop originals first
        for i in idea_ids:
            if i != merged_id:
                self.idea_pool.delete(i)
        # Add/replace merged
        if self.idea_pool.get(merged_id) is None:
            self.idea_pool.add(replacement)
        return merged_id

    # --- Persistence helper ---

    def _persist(self, idea: StoredIdea) -> None:
        """Write a StoredIdea into the underlying IdeaPool."""
        from backend.models.creative_os import IdeaCategory, Idea
        existing = self.idea_pool.get(idea.id)
        if existing is not None:
            # Idempotent: skip. Re-classification should happen via reclassify().
            return
        dataclass_idea = Idea(
            id=idea.id,
            content=idea.content,
            category=IdeaCategory(idea.category),
            source_stage=idea.source_stage,
            source_context=idea.source_context,
            related_elements=[],
            confidence=idea.confidence,
            status="active",
        )
        self.idea_pool.add(dataclass_idea)
```

```python
"""Inspiration REST API — /api/v1/projects/{id}/ideas (F1.9.6 L438).

7 endpoints + 1 cross-project browse endpoint:
- GET    /ideas                    list (filters: category, source_stage, status, source_project_id)
- POST   /ideas                    manual create (admin path; prefer /capture)
- POST   /ideas/capture            manual trigger from UI (creates with classifier call)
- PUT    /ideas/{idea_id}          update (reclassify / edit / mark_invalid)
- DELETE /ideas/{idea_id}          delete
- POST   /ideas/merge              merge N → 1
- POST   /ideas/split              split 1 → N
- POST   /ideas/bulk-import        cross-project import (write to current project)
"""
from __future__ import annotations

import logging
from typing import Optional

from fastapi import APIRouter, HTTPException, Query
from pydantic import BaseModel, Field

from backend.config import settings
from backend.creative_os.idea_pool import IdeaPool
from backend.inspiration import (
    InspirationRouter, apply_multi_class_rules,
)
from backend.inspiration.classifier import InspirationClassifier
from backend.inspiration.models import ConversationTurn, IDEA_CATEGORIES

def _resolve_project_dir(project_id: str):
    project_dir = settings.projects_dir / project_id
    if not project_dir.exists() or not (project_dir / "project.json").exists():
        raise HTTPException(status_code=404, detail={
            "error": True, "code": "PROJECT_NOT_FOUND",
            "message": f"项目 {project_id} 不存在", "detail": {},
        })
    return project_dir


def _make_router(project_id: str) -> InspirationRouter:
    project_dir = _resolve_project_dir(project_id)
    pool = IdeaPool(project_dir)
    clf = InspirationClassifier(model_router=get_model_router())
    return InspirationRouter(classifier=clf, idea_pool=pool, project_id=project_id)


def _idea_to_dict(idea) -> dict:
    return {
        "id": idea.id,
        "content": idea.content,
        "category": idea.category.value if hasattr(idea.category, "value") else idea.category,
        "source_stage": idea.source_stage,
        "source_context": idea.source_context,
        "related_elements": idea.related_elements,
        "confidence": idea.confidence,
        "status": idea.status,
        "created_at": idea.created_at,
        "updated_at": idea.updated_at,
    }

@router.get("")
async def list_ideas(
    project_id: str,
    category: Optional[str] = Query(None),
    source_stage: Optional[str] = Query(None),
    status: str = Query("active"),
    source_project_id: Optional[str] = Query(None),
):
    """List ideas. If `source_project_id` is provided, list that project's
    ideas instead (read-only, used for cross-project browse)."""
    target_id = source_project_id or project_id
    project_dir = _resolve_project_dir(target_id)
    pool = IdeaPool(project_dir)

    cat = None
    if category:
        if category not in IDEA_CATEGORIES:
            raise HTTPException(status_code=400, detail={
                "error": True, "code": "VALIDATION_ERROR",
                "message": f"无效类别: {category}",
                "detail": {"valid": list(IDEA_CATEGORIES)},
            })
        cat = category  # IdeaPool.list accepts str OR IdeaCategory

    ideas = pool.list(category=cat, source_stage=source_stage, status=status)
    return {
        "error": False, "code": "OK", "message": "",
        "detail": [_idea_to_dict(i) for i in ideas],
    }
```

```typescript
// frontend/src/api/inspiration.ts
import { ApiError } from "./client";

const API_BASE = "/api";
const TIMEOUT_MS = 60_000;

export type IdeaCategory =
  | "设定灵感" | "剧情想法" | "角色灵感" | "风格偏好" | "写作灵感";

export type Sensitivity = "low" | "medium" | "high";

export interface Idea {
  id: string;
  content: string;
  category: IdeaCategory;
  source_stage: string;
  source_context: string;
  related_elements: string[];
  confidence: number;
  status: string;
  created_at: string;
  updated_at: string;
}

export interface CaptureRequest {
  content: string;
  stage: string;
  context?: string;
}

export interface ListFilters {
  category?: IdeaCategory;
  source_stage?: string;
  status?: string;
  source_project_id?: string;
}

async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
  const ctrl = new AbortController();
  const timer = setTimeout(() => ctrl.abort(), TIMEOUT_MS);
  let res: Response;
  try {
    res = await fetch(`${API_BASE}${path}`, {
      method,
      headers: body ? { "Content-Type": "application/json" } : undefined,
      body: body ? JSON.stringify(body) : undefined,
      signal: ctrl.signal,
    });
  } finally {
    clearTimeout(timer);
  }
  const json = await res.json();
  if (json.error) {
    throw new ApiError(json.code || "UNKNOWN", json.message || "请求失败",
                       json.detail || {});
  }
  return (json.detail as T) ?? (json as T);
}

export async function listIdeas(projectId: string, filters: ListFilters = {}): Promise<Idea[]> {
  const qs = new URLSearchParams();
  if (filters.category) qs.set("category", filters.category);
  if (filters.source_stage) qs.set("source_stage", filters.source_stage);
  if (filters.status) qs.set("status", filters.status);
  if (filters.source_project_id) qs.set("source_project_id", filters.source_project_id);
  const query = qs.toString();
  return request<Idea[]>("GET",
    `/v1/projects/${encodeURIComponent(projectId)}/ideas${query ? `?${query}` : ""}`);
}

export async function captureIdea(projectId: string, req: CaptureRequest): Promise<Idea> {
  return request<Idea>("POST",
    `/v1/projects/${encodeURIComponent(projectId)}/ideas/capture`, req);
}

export async function updateIdea(projectId: string, ideaId: string,
                                  patch: Partial<Idea>): Promise<Idea> {
  return request<Idea>("PUT",
    `/v1/projects/${encodeURIComponent(projectId)}/ideas/${encodeURIComponent(ideaId)}`,
    patch);
}

export async function deleteIdea(projectId: string, ideaId: string): Promise<void> {
  await request<unknown>("DELETE",
    `/v1/projects/${encodeURIComponent(projectId)}/ideas/${encodeURIComponent(ideaId)}`);
}

export async function mergeIdeas(projectId: string, ideaIds: string[]): Promise<string> {
  return request<string>("POST",
    `/v1/projects/${encodeURIComponent(projectId)}/ideas/merge`,
    { idea_ids: ideaIds });
}

export async function splitIdea(projectId: string, ideaId: string,
                                newContents: string[]): Promise<string[]> {
  return request<string[]>("POST",
    `/v1/projects/${encodeURIComponent(projectId)}/ideas/split`,
    { idea_id: ideaId, new_contents: newContents });
}

export async function bulkImportIdeas(targetProjectId: string,
                                       payload: { source_project_id: string;
                                                  idea_ids: string[] }):
  Promise<{ imported: string[]; count: number }> {
  return request<{ imported: string[]; count: number }>(
    "POST",
    `/v1/projects/${encodeURIComponent(targetProjectId)}/ideas/bulk-import`,
    payload);
}

export async function getSensitivity(projectId: string): Promise<Sensitivity> {
  const url = `/settings/inspiration-sensitivity?project_id=${encodeURIComponent(projectId)}`;
  const out = await request<{ sensitivity: Sensitivity }>("GET", url);
  return out.sensitivity;
}

export async function setSensitivity(projectId: string, value: Sensitivity): Promise<void> {
  await request<unknown>("PUT", "/settings/inspiration-sensitivity",
    { project_id: projectId, sensitivity: value });
}
```

```typescript
  }, [projectId, JSON.stringify(filters)]);

  useEffect(() => { refresh(); }, [refresh]);

  const capture = useCallback(async (req: CaptureRequest) => {
    if (!projectId) return null;
    const created = await insp.captureIdea(projectId, req);
    await refresh();
    return created;
  }, [projectId, refresh]);

  const reclassify = useCallback(async (ideaId: string, newCat: string) => {
    if (!projectId) return;
    await insp.updateIdea(projectId, ideaId, { category: newCat as any });
    await refresh();
  }, [projectId, refresh]);

  const edit = useCallback(async (ideaId: string, content: string) => {
    if (!projectId) return;
    await insp.updateIdea(projectId, ideaId, { content });
    await refresh();
  }, [projectId, refresh]);

  const markInvalid = useCallback(async (ideaId: string) => {
    if (!projectId) return;
    await insp.updateIdea(projectId, ideaId, { status: "invalid" as any });
    await refresh();
  }, [projectId, refresh]);

  const merge = useCallback(async (ids: string[]) => {
    if (!projectId) return null;
    const merged = await insp.mergeIdeas(projectId, ids);
    await refresh();
    return merged;
  }, [projectId, refresh]);

  const split = useCallback(async (ideaId: string, newContents: string[]) => {
    if (!projectId) return [];
    const newIds = await insp.splitIdea(projectId, ideaId, newContents);
    await refresh();
    return newIds;
  }, [projectId, refresh]);

  const remove = useCallback(async (ideaId: string) => {
    if (!projectId) return;
    await insp.deleteIdea(projectId, ideaId);
    await refresh();
  }, [projectId, refresh]);

  return { ideas, loading, error, refresh,
           capture, reclassify, edit, markInvalid, merge, split, remove };
}

export function useSensitivity(projectId: string | undefined) {
  const [sensitivity, setSens] = useState<Sensitivity>("medium");
  const [loading, setLoading] = useState(false);

  const refresh = useCallback(async () => {
    if (!projectId) return;
    setLoading(true);
    try {
      setSens(await insp.getSensitivity(projectId));
    } finally { setLoading(false); }
  }, [projectId]);

  useEffect(() => { refresh(); }, [refresh]);

  const update = useCallback(async (next: Sensitivity) => {
    if (!projectId) return;
    await insp.setSensitivity(projectId, next);
    setSens(next);
  }, [projectId]);

  return { sensitivity, loading, update };
}
```

```tsx
    } finally {
      setBusy(false);
    }
  };

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/40">
      <GlassPanel className="w-full max-w-md space-y-3">

        <textarea
          className="w-full h-32 rounded border border-outline-variant bg-surface-container p-2 text-sm text-white"
          placeholder="输入灵感文本"
          value={content}
          onChange={(e) => setContent(e.target.value)}
        />
        {err && <div className="text-xs text-red-400">{err}</div>}
        <div className="flex justify-end gap-2">
          <button
            onClick={onClose}
            className="rounded border border-system-log/20 px-3 py-1 text-xs text-system-log/60"
```

```tsx
import { useEffect, useState } from "react";
import api from "../../api/client";
import { Idea, listIdeas, bulkImportIdeas } from "../../api/inspiration";
import GlassPanel from "../shared/GlassPanel";

interface Props {
  targetProjectId: string;
}

export default function CrossProjectImport({ targetProjectId }: Props) {
  const [enabled, setEnabled] = useState(false);
  const [projects, setProjects] = useState<{ id: string; title: string }[]>([]);
  const [sourceId, setSourceId] = useState("");
  const [ideas, setIdeas] = useState<Idea[]>([]);
  const [selected, setSelected] = useState<Set<string>>(new Set());
  const [busy, setBusy] = useState(false);
  const [msg, setMsg] = useState("");

  useEffect(() => {
    if (!enabled) return;
    api.listProjects().then((list: any[]) => {
      setProjects(list.filter((p) => p.id !== targetProjectId));
    }).catch(() => setProjects([]));
  }, [enabled, targetProjectId]);

  useEffect(() => {
    if (!sourceId) {
      setIdeas([]);
      return;
    }
    listIdeas(targetProjectId, { source_project_id: sourceId, status: "active" })
      .then(setIdeas)
      .catch(() => setIdeas([]));
  }, [sourceId, targetProjectId]);

  const toggleIdea = (id: string) => {
    setSelected((prev) => {
      const next = new Set(prev);
      if (next.has(id)) next.delete(id); else next.add(id);
      return next;
    });
  };

  const doImport = async () => {
    if (!sourceId || selected.size === 0) return;
    setBusy(true);
    setMsg("");
    try {
      const result = await bulkImportIdeas(targetProjectId, {
        source_project_id: sourceId, idea_ids: Array.from(selected),
      });
      setMsg(`已导入 ${result.count} 条灵感`);
      setSelected(new Set());
    } catch (e: any) {
      setMsg(e?.message || "导入失败");
    } finally {
      setBusy(false);
    }
  };

  if (!enabled) {
    return (
      <label className="flex items-center gap-2 text-xs text-system-log/60">
        <input
          type="checkbox"
          aria-label="从已有项目借鉴灵感"
          checked={enabled}
          onChange={(e) => setEnabled(e.target.checked)}
        />
        从已有项目借鉴灵感
      </label>
    );
  }

  return (
    <GlassPanel className="space-y-3">
      <label className="flex items-center gap-2 text-xs text-system-log/60">
        <input
          type="checkbox"
          aria-label="从已有项目借鉴灵感"
          checked={enabled}
          onChange={(e) => setEnabled(e.target.checked)}
        />
        从已有项目借鉴灵感
      </label>
      <label className="block text-xs text-system-log/50">
        来源项目
        <select
          aria-label="选择来源项目"
          value={sourceId}
          onChange={(e) => setSourceId(e.target.value)}
          className="ml-2 bg-surface-container border border-outline-variant rounded px-2 py-1 text-white"
        >
          <option value="">-- 选择 --</option>
          {projects.map((p) => <option key={p.id} value={p.id}>{p.title}</option>)}
        </select>
      </label>

      {ideas.length > 0 && (
        <div className="max-h-64 overflow-y-auto space-y-1">
          {ideas.map((i) => (
            <label key={i.id} className="flex items-start gap-2 text-xs text-system-log/80">
              <input
                type="checkbox"
                aria-label="选择灵感"
                checked={selected.has(i.id)}
                onChange={() => toggleIdea(i.id)}
              />
              <span className="flex-1">
                <span className="text-system-log/40 font-mono mr-1">[{i.category}]</span>
                {i.content}
              </span>
            </label>
          ))}
        </div>
      )}

      <div className="flex items-center gap-3">
        <button
          onClick={doImport}
          disabled={busy || !sourceId || selected.size === 0}
          className="rounded bg-accent-purple px-3 py-1 text-xs text-white disabled:opacity-50"
        >
          {busy ? "导入中..." : `导入所选 (${selected.size})`}
        </button>
        {msg && <span className="text-xs text-system-log/60">{msg}</span>}
      </div>
    </GlassPanel>
  );
}
```
