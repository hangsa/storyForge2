# v1.8 — Home Page Refactor

**Date:** 2026-07-09
**Branch:** v1.8
**Status:** Draft, pending review

## Context

StoryForge2 currently uses `ProjectListPage` as the home route `/`. It shows a project list with search and bulk-delete actions, plus a "新建项目" modal that collects basic intent / title / genre / target-length. Aggregate statistics (total books, total chapters, total words, stage distribution) are **not computed anywhere**; there is no system-level overview. The existing MainLayout sidebar is bypassed on the home page, so users see a different chrome than on inner pages.

This spec introduces a refactored home page modeled on plotPilot's two-column home (StatsSidebar + main column). It provides a unified landing experience and the entry point for project creation, replacing `ProjectListPage` with `HomePage`.

## Goals

1. Provide a left "StatsSidebar" with aggregated stats overview + quick actions.
2. Restructure the right main area into three vertically stacked sections: manifesto, create form, book shelf.
3. Add a backend aggregation endpoint `GET /api/project/stats`.
4. Surface the home as the canonical landing experience — match MainLayout's sidebar presence on inner pages so users feel continuity.

## Non-Goals

- Stats visualizations (charts/graphs) — kept as simple number tiles for v1.8.
- New project types or creation flows beyond what's already supported (`intent / title / genre / min_words / free_text`).
- Search facets beyond title (no tag-based or stage-based filter in v1.8).
- AI 控制台 / 提示词广场 functionality — placeholder buttons only.

## Data Flow

### Page Load

```
HomePage mount
  → useProjectStats() → GET /api/project/stats
  → 同时调用 GET /api/project/list
  → 渲染 StatsSidebar (stats) + BookShelf (projects list)
```

### Create Project

```
User fills CreateProjectCard → click "建档并进入工作台"
  → POST /api/project/create { intent, title?, genre, min_words, free_text? }
  → 拿到 { id: "proj_xxx", ... }
  → 设置 HomePage 的 wizardProjectId state
  → InitWizardModal mount (mount 在 HomePage 内，作为同级覆盖层)
  → POST /api/conductor/advance (target STAGE1)  // 与现有 ProjectListPage 行为一致
```

### Refresh / 刷新列表

`StatsSidebar.QuickActions` 中的"刷新列表"按钮调用 `useProjectStats.invalidate()` + `useProjects.invalidate()`。

## API Contract

### New: `GET /api/project/stats`

**Response 200:**
```json
{
  "total_books": 12,
  "total_chapters": 87,
  "total_words": 214000,
  "stage_distribution": {
    "STAGE1": 3,
    "STAGE2": 1,
    "STAGE3": 0,
    "STAGE4": 5,
    "STAGE5": 0,
    "STAGE6": 0,
    "COMPLETED": 4
  }
}
```

**Implementation:**
- Scan `projects/*/project.json` for stage counts.
- Scan `projects/*/chapters/*.json` (or aggregated chapter index) for chapter/word counts.
- Aggregation done server-side; clients never enumerate project files.

### Reused: `GET /api/project/list`, `POST /api/project/create`

No changes to existing payloads or behavior.

## UI Specification

### StatsSidebar

- Width: 300px default, collapsible to 52px (state in `localStorage["storyforge.home.sidebar.collapsed"]`).
- Vertical sections: BrandHeader (gradient) → StatsOverview → QuickActions.
- BrandHeader shows app logo + name + collapse toggle.
- StatsOverview shows 3 number tiles in a row + StageDistribution list (each stage as dot + label + count).
- QuickActions shows 2×2 grid: AI 控制台 (disabled, tooltip "即将推出") / 提示词广场 (disabled) / 刷新列表 (active) / 占位 (disabled "...").

### MainContent

- Padding 32–48px; max-width 1200px.
- Section 1 (Manifesto): centered title + subtitle. Subtle background gradient.
- Section 2 (CreateProjectCard): bordered card with form fields:
  - 创作意图 (textarea, required)
  - 项目名称 (input, optional)
  - 题材模板 (select)
  - 目标篇幅 (radio group: 短篇 / 中篇 / 长篇)
  - 高级 (collapsible): 章节数 + 每章字数
  - Primary button "建档并进入工作台"
- Section 3 (BookShelf): section header + count + search input + batch-delete button. Body: horizontal flex of fixed-width book cards (260px each), overflow-x scroll. Cards show: stage dot, stage tag, title, genre, chapter/word count, hover-revealed checkbox + delete popconfirm.
- "查看全部" button below the shelf opens BookShelfModal (full-screen modal with own search + wrapping grid of all book cards).

## Error Handling

| Scenario | Behavior |
|---|---|
| `GET /api/project/stats` fails | Stats tiles show "—" placeholders; main area still renders. |
| `POST /api/project/create` fails | Toast red; form preserves user input. |
| Empty project list | BookShelf renders empty state ("还没有项目，点击新建按钮开始"). |
| Search returns no results | BookShelf shows "未找到匹配项目" message. |
