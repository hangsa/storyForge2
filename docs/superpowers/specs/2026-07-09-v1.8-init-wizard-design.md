# v1.8 — Init Wizard

**Date:** 2026-07-09
**Branch:** v1.8
**Status:** Draft, pending review

## Context

After creating a project in `HomePage`, users currently land directly on `/project/:id/stage1` (or, after wiring, `/project/:id/workspace`). The "initialization" experience — concept discussion, worldview, characters, outline — is delivered as six separate `Stage1Page` … `Stage3Page` URLs with the Conductor state machine enforcing sequential progression. There's no guided, in-modal flow.

This spec introduces a 6-step **Init Wizard** modal that opens immediately after project creation and walks the user through concept → worldview → character → map (placeholder) → outline → chapter outline. The wizard is a thin UI shell that **wraps existing Stage generation/save APIs**; no new agent logic is introduced. The wizard is also accessible as a deep link `/project/:id/wizard` for users who abandon it mid-flow.

## Goals

1. Provide a single, guided initialization experience after project creation.
2. Reuse existing Stage 1–3 generation and save endpoints without modification.
3. Add 2 fields to the World step (社会结构, 历史文化) inside the 时代与地理 section, persisting to `world.json`.
4. Preserve deep-link accessibility to `Stage1Page` … `Stage3Page` as full-page alternatives.
5. Provide a placeholder "地图系统" step (deferred to a future iteration; only "skip" is enabled).

## Non-Goals

- Replacing Stage 1–3 page components. They remain accessible at `/project/:id/stage1..3`.
- LLM streaming / SSE wiring (existing endpoints are POST-JSON, awaited; wizard preserves that contract).
- Map system actual implementation. The step is a "功能即将推出" placeholder card.
- Per-step LLM model tier selection. Uses whatever the existing Stage APIs already route to.

## Architecture

### Wizard Steps

| # | Step | Reused Endpoint | Persisted To | Notes |
|---|---|---|---|---|
| 1 | 概念讨论 | `POST /api/stage1/generate` → `POST /api/stage1/save` | `concept_and_dna.json` | Pre-fills `intent` from HomePage |
| 2 | 世界观 | `POST /api/stage2/generate-world` → `POST /api/stage2/save` | `world.json` | Adds 社会结构 + 历史文化 inside 时代与地理 |
| 3 | 角色设计 | `POST /api/stage2/generate-character` → `POST /api/stage2/save` | `characters.json` | One or more characters |
| 4 | 地图系统 | — | — | Placeholder; only "跳过" enabled. Skipping marks step as `skipped` in `completedSteps` and advances to step 5 without writing any data. |
| 5 | 全书大纲 | `POST /api/stage3/generate-outline` → `POST /api/stage3/save` | `outline.json` | **Chapter-level overview only** — generates `outline.chapters[]` with `chapter_number`, `title`, `summary` per chapter (no scenes yet) |
| 6 | 章节大纲 | `POST /api/stage3/generate-chapter-outline` → `POST /api/stage3/save` | `outline.json` | **Scene-level expansion** — for each chapter, populates `chapter.scene_plan[]` with `scene_number`, `title`, `beats`, `required_logs` |

### Step State

Each step has 3 states:
- **Idle** — Show "开始生成" button + (optional) pre-filled context.
- **Generating** — Show skeleton placeholder + spinner; await API; no user input.
- **Completed** — Show form fields populated by generation result, all editable; show "重新生成" button.

Transitions: Idle → Generating → Completed. User can return from Completed → Generating (click 重新生成). User cannot skip from Idle directly to Completed; they must trigger generation.

### Navigation

- Step indicator at top: shows current step + completed steps (✓) + remaining steps.
- Click any step in the indicator to jump to it (loads its persisted data, if any).
- Footer: "上一步" / "下一步" buttons. "上一步" disabled at step 1. "下一步" disabled while in Generating state.
- Close (×) button always disabled — prevents mid-flow data loss.

## Data Flow

### Step Generation

```
User clicks "开始生成" on ConceptStep (step 1)
  → useWizard.startStep(1)
  → state.currentStep = 1, state.status = 'generating'
  → POST /api/stage1/generate { project_id }
  → 接收 concept_and_dna dict
  → state.status = 'completed', state.data = dict
  → ConceptStep re-renders with form fields populated
```

### Step Save (on "下一步")

```
User clicks "下一步" on completed step
  → useWizard.saveStep(currentStep, data)
  → POST /api/stage1/save { project_id, ...data }   (step 1)
  → 持久化到 concept_and_dna.json
  → state.completedSteps.push(currentStep)
  → state.currentStep += 1
  → 新 step 加载（Idle 状态，等待用户点击"开始生成"）
```

### Wizard Completion

```
User clicks "完成" on ChapterOutlineStep (step 6)
  → saveStep(6) 写入 outline.json
  → POST /api/conductor/advance { target: STAGE4 }
  → navigate(/project/:id/workspace?mode=manual)
```

### Mid-Flow Network Failure

```
Generating → network error
  → state.status = 'error'
  → Step shows red banner with retry button
  → 点击重试 → state.status = 'generating', 重新调用 API
  → sessionStorage 持久化 state.completedSteps + state.data（防刷新丢失）
```

## World Step — New Fields

The Stage2 worldview output is preserved exactly. Two new fields are added **inside the 时代与地理 section**:

```python
class World(BaseModel):
    era: str
    geography: str
    era_social_structure: Optional[str] = None   # NEW
    era_cultural_history: Optional[str] = None   # NEW
    power_system: PowerSystem
    core_rules: List[str]
    factions: List[Faction]
```

**Prompt update** (`backend/prompts/world_generation.yaml`):
Add to the "时代与地理" output spec:
```yaml
- era_social_structure: |
    描述当前时代的社会结构，包括权力分配、阶层关系、组织形态
- era_cultural_history: |
    描述关键历史事件、文化传统、时代精神对当下世界的影响
```

**UI** in `WorldStep.tsx`:
- Two new `<textarea>` fields under 时代与地理, after `geography`.
- Visual marker: `社会结构 [新增]` and `历史文化 [新增]` labels with subtle accent color.

## Error Handling

| Scenario | Behavior |
|---|---|
| Generation API error | Step shows red banner + "重试" button; other steps unaffected. |
| Save API error | Toast red; data preserved in wizard state; user can retry save without regenerating. |
| Network offline | sessionStorage persists currentStep + completedSteps + data; reload recovers. |
| `/api/conductor/advance` fails on completion | Wizard stays on step 6 with error toast; user retries "完成". |
| User navigates away mid-wizard | sessionStorage preserves state; deep-link `/wizard` resumes. |
