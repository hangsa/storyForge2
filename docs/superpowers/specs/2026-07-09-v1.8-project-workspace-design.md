# v1.8 — Project Workspace

**Date:** 2026-07-09
**Branch:** v1.8
**Status:** Draft, pending review

## Context

The current Stage4 "writing center" (`Stage4Page`) is a per-chapter / per-scene manual editor. There's no project-level overview, no autopilot mode, and no concept/world/character/outline context readily visible while writing. Diagnostic (Stage5) and export (Stage6) live on separate routes, requiring users to leave the writing flow.

This spec introduces a unified **Project Workspace** with two modes:
- **Managed mode** — a chapter-grid dashboard with autopilot AI control center (UI scaffolding only; AI orchestration backend deferred to v1.9+).
- **Manual mode** — the existing per-scene editor, repurposed as the project's day-to-day editing view.

Users can switch between modes via the top-bar mode switcher or by clicking a chapter in the managed dashboard (which auto-enters manual mode for that chapter).

This spec replaces `Stage4Page`'s route `/project/:id/stage4` with `/project/:id/workspace`. The old URL **redirects** to the new workspace.

## Goals

1. Provide a project-level overview (chapter grid + status) as the workspace's default landing experience.
2. Provide a per-chapter / per-scene manual editor as the workspace's editing view.
3. Allow seamless switching between modes with confirmation when AI work is in progress.
4. Embed Stage1-3 + Stage5/6 functionality into the workspace's right panel (concept/world/character/outline/diagnosis/export).
5. Reserve all real AI autopilot orchestration as future work; ship UI scaffolding only.

## Non-Goals

- Actual AI autopilot orchestration (looping, Token budgeting, real-time reader tension monitoring, etc.). UI is scaffolded with mock data only.
- LLM streaming for managed-mode batch generation.
- WebSocket / SSE connections from frontend (no real-time events in v1.8).
- Refactoring Stage5 / Stage6 backend. Their data files and APIs are reused as-is.
- Replacing StyleSandboxPage, ChapterReviewPage, ImpactAnalysisPage, StoryOSPage. They remain separate routes under MainLayout.

## Architecture

### Modes

| Mode | Purpose | Trigger |
|---|---|---|
| `managed` | Project-level dashboard + AI control center | Default if user has not edited any chapter, OR explicit top-bar toggle |
| `manual` | Per-chapter / per-scene editor | User clicks a chapter in dashboard, OR explicit top-bar toggle |

State persisted in URL: `?mode=managed | manual` and localStorage `storyforge.workspace.mode`.

### Routing

| Path | Component |
|---|---|
| `/project/:id/workspace?mode=managed` | WorkspacePage in managed mode |
| `/project/:id/workspace?mode=manual&chapter=N&scene=M` | WorkspacePage in manual mode |
| `/project/:id/workspace?panel=diagnosis` | Right panel forced to diagnosis tab |
| `/project/:id/stage4` | **Redirect →** `/project/:id/workspace?mode=manual` |
| `/project/:id/stage5` | **Redirect →** `/project/:id/workspace?mode=manual&panel=diagnosis` |
| `/project/:id/stage6` | **Redirect →** `/project/:id/workspace?mode=manual&panel=export` |

### Managed Mode — UI Details

#### Top Bar
- Project name + status badge: in managed mode shows "🤖 托管中" or "⏸ 已暂停" (whichever applies); in manual mode shows "✍ 手动模式". Never show both.
- Progress ring (X/Y chapters complete) + total word count + elapsed time.
- Mode switcher (segmented control).
- Action buttons: 暂停托管 / 配置 / AI 工具 (disabled placeholder).

#### Status Strip
- Below top bar: "🤖 AI 正在生成 X · 调用模型 · 预估/已耗时 · 队列预览".
- Hidden when no autopilot session is active.

#### Chapter Grid
- Auto-fill grid; min cell 140px.
- Color states:
  - 绿底绿边 ✓ — 已完成
  - 蓝底蓝边 ✎ (with progress bar at bottom) — 写作中
  - 黄底黄边 📋 — 已规划但未开始
  - 暗灰底虚线 ⏳ — 待规划
- Click a cell: navigates to manual mode + that chapter; if cell is "写作中", opens confirmation modal ("等待完成" vs "立即接管").

#### AI Control Center (right panel, managed mode only)
- 4 tabs: 决策流 / 队列 / 检查 / 干预.
- 决策流: reverse-chronological event log (completion, retry, decision, warning).
- Mocked events only in v1.8 (no live WebSocket).

### Manual Mode — UI Details

#### Top Bar
- Project name + manual badge.
- Chapter/scene breadcrumb.
- Mode switcher.
- Word count + progress bar + AI 工具 (disabled) + 保存草稿.

#### Chapter Tree (left)
- View mode: 扁平 / 树形 / 按幕.
- Click chapter to expand scenes.
- Bottom: + 新章节 / 刷新 buttons.

#### Writing Area (center)
- Scene header (chapter + scene title + 大纲 / 角色状态 / 历史章节 buttons).
- Editor body (textarea, **serif font (Georgia / similar)**, SF_LOG tags rendered as gray italic).
- Footer: location / word count / log count / Fact Guard status + 重新生成 / Fact Guard / 保存草稿.
- **If the user enters manual mode for a chapter that doesn't exist yet** (drill-down from a "待规划" cell), the WritingArea shows an empty state: "本章节尚未生成大纲" + a primary button "前往生成大纲" that opens the OutlineTab of the right panel and scrolls to that chapter's row.

#### Context Panel (right, **manual mode only**)
- 6 tabs: 概念 / 世界观 / 角色 / 大纲 / 诊断 / 导出.
- Active tab persisted in URL `?panel=`.
- Tab content reuses existing Stage1/2/3/5/6 components (lazy-loaded on first switch).
- **In managed mode, this panel is NOT mounted.** Managed mode uses `ManagedAIControlPanel` instead (see below).

### Mode Switch — Confirmation Flow

```
User clicks "✍ 手动模式" in top bar (managed → manual)
  → ModeSwitchConfirmModal opens
  → Shows: 当前 AI 状态 (正在生成 X) + 队列 (N 任务) + 已规划章数
  → Checkbox: "切换前先把当前场景生成完成（推荐）"
  → Buttons: 取消 / 切换到手动模式
```

```
User clicks "🤖 托管模式" in top bar (manual → managed)
  → ManagedStartModal opens (首次) 或 简单确认 (后续)
  → Shows: 推进范围 / 推进节奏 / AI 决策策略 / 通知规则
  → Buttons: 稍后再说 / 启动托管
```

## Data Flow

### Page Load — Managed Mode

```
WorkspacePage mount with ?mode=managed
  → useWorkspaceMode resolves to 'managed'
  → ManagedDashboard mounts
  → Fetch project status (existing /api/project/:id/status)
  → Build chapter grid from outline.json (existing read)
  → Render dashboard with status cells
  → ManagedAIControlPanel renders with mocked decision stream
```

### Page Load — Manual Mode

```
WorkspacePage mount with ?mode=manual&chapter=N&scene=M
  → useWorkspaceMode resolves to 'manual'
  → ChapterTreePanel mounts + selects chapter N
  → WritingArea mounts with scene M data
  → ContextPanel mounts with default tab (concept)
```

### Mode Switch — Managed → Manual

```
User clicks "✍ 手动模式"
  → ModeSwitchConfirmModal opens
  → User confirms
  → URL changes to ?mode=manual&chapter=N&scene=M (last manual position)
  → WorkspacePage re-mounts in manual mode
```

### Mode Switch — Manual → Managed

```
User clicks "🤖 托管模式"
  → ManagedStartModal opens (only first time per project)
  → User configures + confirms
  → ManagedDashboard mounts; status strip shows mock "AI 正在生成..."
```

### Drill-Down from Dashboard

```
User clicks a chapter cell in ManagedDashboard
  → if cell.status == 'completed' → switch to manual mode + load that chapter's first scene
  → if cell.status == 'writing' → Modal asks "等待完成" or "立即接管" (if 立即接管, switch to manual mode + open that chapter)
  → if cell.status == 'planned' → switch to manual mode + load that chapter's first scene
  → if cell.status == 'pending' (待规划) → switch to manual mode + WritingArea shows empty state ("本章节尚未生成大纲" + button "前往生成大纲" → switches to OutlineTab in ContextPanel and scrolls to that chapter)
```

## Error Handling

| Scenario | Behavior |
|---|---|
| Project not found (404) | Redirect to `/`. |
| `?chapter=N` out of range | Fall back to first chapter / first scene. |
| `?panel=` invalid value | Default to "concept" tab. |
| Mode switch fails | Toast red; stay on current mode. |
| Right panel tab component throws | Catch + show "加载失败 [重试]" inline. |
| Mode toggle during AI generation (mocked) | ModeSwitchConfirmModal shows mock AI state. |
